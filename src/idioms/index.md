# สำนวน (Idioms)

[สำนวน](https://en.wikipedia.org/wiki/Programming_idiom) คือรูปแบบ แนวปฏิบัติ และแพตเทิร์นที่ใช้กันทั่วไปซึ่งชุมชนยอมรับร่วมกันโดยส่วนใหญ่ การเขียนโค้ดอย่างมีสำนวนช่วยให้นักพัฒนาคนอื่นเข้าใจได้ดีขึ้นว่าเกิดอะไรขึ้น

ท้ายที่สุดแล้ว คอมพิวเตอร์สนใจเพียงโค้ดเครื่อง (machine code) ที่คอมไพเลอร์สร้างออกมา ขณะที่ซอร์สโค้ดมีประโยชน์หลักต่อนักพัฒนา ดังนั้น เมื่อเรามีชั้นนามธรรมนี้แล้ว ทำไมไม่ทำให้มันอ่านง่ายขึ้นเสียเลย?

จำ[หลักการ KISS](https://en.wikipedia.org/wiki/KISS_principle) ไว้ให้ดี: "Keep It Simple, Stupid" หลักการนี้กล่าวว่า "ระบบส่วนใหญ่ทำงานได้ดีที่สุดเมื่อถูกทำให้เรียบง่ายแทนที่จะซับซ้อน ดังนั้น ความเรียบง่ายจึงควรเป็นเป้าหมายสำคัญในการออกแบบ และควรหลีกเลี่ยงความซับซ้อนที่ไม่จำเป็น"

> โค้ดมีไว้ให้มนุษย์เข้าใจ ไม่ใช่ให้คอมพิวเตอร์
