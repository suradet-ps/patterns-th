# สำนวนการเขียนโค้ด (Idioms)

[สำนวนการเขียนโค้ด (Idioms)](https://en.wikipedia.org/wiki/Programming_idiom) คือรูปแบบ สไตล์ แนวทางปฏิบัติ และแพตเทิร์นที่ชุมชนนักพัฒนาส่วนใหญ่ยอมรับและใช้ร่วมกัน การเขียนโค้ดตามแนวทางที่ถูกต้องเหมาะสมของภาษา (Idiomatic Code) จะช่วยให้นักพัฒนาคนอื่นสามารถอ่านและทำความเข้าใจเจตนาของโค้ดได้รวดเร็วและชัดเจนยิ่งขึ้น

เพราะในท้ายที่สุดแล้ว คอมพิวเตอร์สนใจเพียงแค่ภาษาเครื่อง (Machine Code) ที่คอมไพเลอร์สร้างขึ้นมาเท่านั้น แต่ซอร์สโค้ดถูกเขียนขึ้นเพื่อให้มนุษย์ด้วยกันอ่านและดูแลรักษา ในเมื่อภาษาโปรแกรมคือชั้นของแอบสแตรกชันที่สร้างขึ้นมาเพื่อเรา แล้วทำไมเราถึงไม่ทำให้มันอ่านง่ายที่สุดล่ะ?

ขอให้ระลึกถึง[หลักการ KISS](https://en.wikipedia.org/wiki/KISS_principle): "Keep It Simple, Stupid" ซึ่งระบุไว้ว่า "ระบบส่วนใหญ่จะทำงานได้ดีที่สุดเมื่อถูกรักษาให้เรียบง่าย ไม่ซับซ้อน ดังนั้น ความเรียบง่ายจึงควรเป็นเป้าหมายสำคัญในการออกแบบ และควรหลีกเลี่ยงความซับซ้อนที่ไม่จำเป็น"

> โค้ดมีไว้ให้มนุษย์ทำความเข้าใจ ไม่ใช่คอมพิวเตอร์
