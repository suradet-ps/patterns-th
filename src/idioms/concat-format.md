# การต่อสตริงด้วย `format!`

## คำอธิบาย

เราสามารถประกอบสตริงขึ้นมาได้โดยใช้เมท็อด `push` และ `push_str` บน `String` ที่แก้ไขได้ หรือใช้โอเปอเรเตอร์ `+` ของมัน อย่างไรก็ตาม มักสะดวกกว่าที่จะใช้ `format!` โดยเฉพาะในกรณีที่มีทั้งสตริงลิเทอรัลและไม่ใช่ลิเทอรัลปนกัน

## ตัวอย่าง

```rust
fn say_hello(name: &str) -> String {
    // We could construct the result string manually.
    // let mut result = "Hello ".to_owned();
    // result.push_str(name);
    // result.push('!');
    // result

    // But using format! is better.
    format!("Hello {name}!")
}
```

## ข้อดี

การใช้ `format!` มักเป็นวิธีที่กระชับและอ่านง่ายที่สุดในการรวมสตริงเข้าด้วยกัน

## ข้อเสีย

มักไม่ใช่วิธีที่มีประสิทธิภาพที่สุดในการรวมสตริง - การเรียก `push` ต่อกันหลายครั้งบนสตริงที่แก้ไขได้มักมีประสิทธิภาพที่สุด (โดยเฉพาะถ้าสตริงถูกจัดสรรขนาดล่วงหน้าตามขนาดที่คาดไว้แล้ว)
