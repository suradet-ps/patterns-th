# ไดนามิกดิสแพตช์บนสแตก

## คำอธิบาย

เราสามารถทำไดนามิกดิสแพตช์ข้ามค่าหลายค่าได้ อย่างไรก็ตาม การทำเช่นนั้นเราจำเป็นต้องประกาศตัวแปรหลายตัวเพื่อผูกกับออบเจกต์ที่ชนิดต่างกัน เพื่อยืดอายุการใช้งาน (lifetime) ตามความจำเป็น เราสามารถใช้การเริ่มต้นแบบมีเงื่อนไขที่เลื่อนออกไป (deferred conditional initialization) ดังที่เห็นด้านล่าง:

## ตัวอย่าง

```rust
use std::io;
use std::fs;

# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let arg = "-";

// We need to describe the type to get dynamic dispatch.
let readable: &mut dyn io::Read = if arg == "-" {
    &mut io::stdin()
} else {
    &mut fs::File::open(arg)?
};

// Read from `readable` here.

# Ok(())
# }
```

## แรงจูงใจ

Rust ทำ monomorphisation กับโค้ดโดยค่าเริ่มต้น หมายความว่าจะมีการสร้างสำเนาโค้ดขึ้นใหม่สำหรับแต่ละชนิดที่ใช้งาน แล้ว optimize แยกกัน แม้วิธีนี้ช่วยให้โค้ดบนเส้นทางที่ทำงานบ่อย (hot path) เร็วมาก แต่ก็ทำให้โค้ดบวมในจุดที่ประสิทธิภาพไม่ใช่สิ่งสำคัญ จึงต้องแลกกับเวลาคอมไพล์และการใช้งานแคช

โชคดีที่ Rust ยอมให้เราใช้ไดนามิกดิสแพตช์ได้ เพียงแต่เราต้องขอใช้อย่างชัดเจน

## ข้อดี

เราไม่จำเป็นต้องจัดสรรหน่วยความจำบนฮีปเลย ไม่ต้องเริ่มต้นสิ่งที่เราจะไม่ใช้ในภายหลัง และไม่ต้องทำ monomorphisation กับโค้ดทั้งหมดที่ตามมาเพื่อให้ทำงานได้ทั้งกับ `File` และ `Stdin`

## ข้อเสีย

ก่อน Rust 1.79.0 โค้ดต้องใช้การผูก `let` สองครั้งพร้อมการเริ่มต้นแบบเลื่อนออกไป ซึ่งมีชิ้นส่วนที่ต้องขยับมากกว่าเวอร์ชันที่ใช้ `Box`:

```rust,ignore
// We still need to ascribe the type for dynamic dispatch.
let readable: Box<dyn io::Read> = if arg == "-" {
    Box::new(io::stdin())
} else {
    Box::new(fs::File::open(arg)?)
};
// Read from `readable` here.
```

โชคดีที่ข้อเสียนี้หมดไปแล้ว เย่!

## การอภิปราย

ตั้งแต่ Rust 1.79.0 เป็นต้นมา คอมไพเลอร์จะยืดอายุของค่าชั่วคราวภายใน `&` หรือ `&mut` ให้ยาวนานที่สุดเท่าที่ทำได้ภายในขอบเขตของฟังก์ชันโดยอัตโนมัติ

หมายความว่าเราเพียงใช้ค่า `&mut` ตรงนี้ได้เลยโดยไม่ต้องกังวลว่าจะต้องเอาสิ่งที่บรรจุอยู่ไปใส่ใน binding `let` ใดๆ (ซึ่งเคยจำเป็นสำหรับการเริ่มต้นแบบเลื่อนออกไป อันเป็นวิธีแก้ปัญหาที่ใช้ก่อนการเปลี่ยนแปลงนั้น)

เรายังคงมีที่สำหรับเก็บแต่ละค่า (แม้ที่นั้นจะเป็นที่อยู่ชั่วคราว) คอมไพเลอร์รู้ขนาดของแต่ละค่า และค่าที่ถูกยืมแต่ละค่ามีอายุยืนยาวกว่าการอ้างอิงทั้งหมดที่ยืมมาจากมัน
