# ส่งตัวแปรเข้าโคลเชอร์

## คำอธิบาย

โดยค่าเริ่มต้น โคลเชอร์จะจับสภาพแวดล้อมของมันด้วยการยืม หรือคุณจะใช้โคลเชอร์แบบ `move` เพื่อย้ายสภาพแวดล้อมทั้งหมดก็ได้ อย่างไรก็ตาม บ่อยครั้งคุณต้องการย้ายตัวแปรเพียงบางตัวเข้าไปในโคลเชอร์ ให้สำเนาข้อมูลบางส่วน ส่งผ่านการอ้างอิง หรือทำการแปลงรูปแบบอื่นๆ

ให้ใช้การผูกตัวแปรใหม่ (variable rebinding) ในขอบเขตแยกต่างหากสำหรับเรื่องนี้

## ตัวอย่าง

ใช้

```rust
use std::rc::Rc;

let num1 = Rc::new(1);
let num2 = Rc::new(2);
let num3 = Rc::new(3);
let closure = {
    // `num1` is moved
    let num2 = num2.clone();  // `num2` is cloned
    let num3 = num3.as_ref();  // `num3` is borrowed
    move || {
        *num1 + *num2 + *num3;
    }
};
```

แทนที่จะเป็น

```rust
use std::rc::Rc;

let num1 = Rc::new(1);
let num2 = Rc::new(2);
let num3 = Rc::new(3);

let num2_cloned = num2.clone();
let num3_borrowed = num3.as_ref();
let closure = move || {
    *num1 + *num2_cloned + *num3_borrowed;
};
```

## ข้อดี

ข้อมูลที่ถูกคัดลอกจะถูกจัดกลุ่มไว้พร้อมกับนิยามของโคลเชอร์ จุดประสงค์ของมันจึงชัดเจนขึ้น และมันจะถูกดรอปทันทีแม้ไม่ได้ถูกใช้ภายในโคลเชอร์

โคลเชอร์ใช้ชื่อตัวแปรเดียวกับโค้ดรอบข้าง ไม่ว่าข้อมูลจะถูกคัดลอกหรือถูกย้าย

## ข้อเสีย

เนื้อความของโคลเชอร์ต้องเยื้องเพิ่มขึ้น
