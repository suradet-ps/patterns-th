# ความสามารถในการแก้ไขชั่วคราว

## คำอธิบาย

บ่อยครั้งจำเป็นต้องเตรียมและประมวลผลข้อมูลบางอย่าง แต่หลังจากนั้นข้อมูลจะถูกตรวจสอบเท่านั้นและไม่ถูกแก้ไขอีก เจตนานี้สามารถแสดงออกอย่างชัดเจนได้โดยนิยามตัวแปรที่แก้ไขได้ใหม่ให้เป็นแบบแก้ไขไม่ได้

ทำได้ทั้งโดยประมวลผลข้อมูลภายในบล็อกซ้อนหรือโดยนิยามตัวแปรใหม่

## ตัวอย่าง

สมมติว่าเวกเตอร์ต้องถูกจัดเรียงก่อนใช้งาน

ใช้บล็อกซ้อน:

```rust,ignore
let data = {
    let mut data = get_vec();
    data.sort();
    data
};

// Here `data` is immutable.
```

ใช้การผูกตัวแปรใหม่:

```rust,ignore
let mut data = get_vec();
data.sort();
let data = data;

// Here `data` is immutable.
```

## ข้อดี

คอมไพเลอร์รับประกันว่าคุณจะไม่เผลอแก้ไขข้อมูลหลังจากจุดหนึ่งเป็นต้นไป

## ข้อเสีย

บล็อกซ้อนต้องเยื้องเนื้อความของบล็อกเพิ่มขึ้น และต้องเพิ่มอีกหนึ่งบรรทัดเพื่อคืนข้อมูลจากบล็อกหรือนิยามตัวแปรใหม่
