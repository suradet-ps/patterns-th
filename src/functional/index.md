# การใช้งาน Rust เชิงฟังก์ชัน

Rust เป็นภาษาที่มีรูปแบบการเขียนโค้ดแบบอิมเพอเรทีฟ (Imperative) แต่ในขณะเดียวกันก็รับเอาแนวคิดและกระบวนทัศน์ของ[การเขียนโปรแกรมเชิงฟังก์ชัน (Functional Programming)](https://en.wikipedia.org/wiki/Functional_programming) เข้ามาผสมผสานไว้อย่างเข้มข้น

> ในทางวิทยาการคอมพิวเตอร์ *การเขียนโปรแกรมเชิงฟังก์ชัน (Functional Programming)* คือกระบวนทัศน์การเขียนโปรแกรมที่สร้างโปรแกรมขึ้นจากการประยุกต์และประกอบฟังก์ชันเข้าด้วยกัน เป็นรูปแบบการเขียนโปรแกรมเชิงประกาศ (Declarative) ซึ่งโครงสร้างของฟังก์ชันจะประกอบขึ้นจากสายธารของนิพจน์ (Expressions) ที่ประเมินและคืนค่าออกมา แทนที่จะเป็นลำดับคำสั่ง (Statements) แบบอิมเพอเรทีฟที่คอยเปลี่ยนแปลงสถานะ (State) ของโปรแกรมไปเรื่อยๆ
