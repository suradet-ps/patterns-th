# การใช้งาน Rust เชิงฟังก์ชัน

Rust เป็นภาษาเชิงอิมเพอเรทีฟ แต่ก็ทำตามกระบวนทัศน์[การเขียนโปรแกรมเชิงฟังก์ชัน](https://en.wikipedia.org/wiki/Functional_programming)หลายประการ

> ในวิทยาการคอมพิวเตอร์ *การเขียนโปรแกรมเชิงฟังก์ชัน* คือกระบวนทัศน์การเขียนโปรแกรมที่สร้างโปรแกรมขึ้นจากการประยุกต์และประกอบฟังก์ชันเข้าด้วยกัน เป็นกระบวนทัศน์การเขียนโปรแกรมแบบประกาศ (declarative) ซึ่งนิยามของฟังก์ชันเป็นต้นไม้ของนิพจน์ที่แต่ละนิพจน์คืนค่า แทนที่จะเป็นลำดับคำสั่งเชิงอิมเพอเรทีฟที่เปลี่ยนสถานะของโปรแกรม
