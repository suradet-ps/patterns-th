# การรีแฟกเตอร์

การรีแฟกเตอร์มีความสำคัญอย่างยิ่งเมื่อเทียบกับหัวข้อเหล่านี้ สิ่งที่สำคัญพอๆ กับหัวข้ออื่นๆ ที่กล่าวถึงในที่นี้ คือวิธีนำโค้ดที่ดีไปสู่โค้ดที่ยอดเยี่ยม

เราสามารถใช้[ดีไซน์แพตเทิร์น](../patterns/index.md)เพื่อทำให้โค้ด [DRY] ขึ้นและวางนัยทั่วไปของนามธรรมได้ เราต้องหลีกเลี่ยง[แอนติแพตเทิร์น](../anti_patterns/index.md)ขณะทำเช่นนั้น ถึงแม้มันอาจดูน่าดึงดูดใจที่จะนำมาใช้ แต่ต้นทุนของมันสูงกว่าประโยชน์ที่ได้รับ

> ทางลัดนำมาซึ่งวันอันยาวนาน

เรายังใช้[สำนวน](../idioms/index.md)เพื่อจัดโครงสร้างโค้ดของเราในแบบที่เข้าใจได้ง่ายได้ด้วย

## การทดสอบ

การทดสอบมีความสำคัญอย่างยิ่งในระหว่างการรีแฟกเตอร์
