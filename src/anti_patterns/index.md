# แอนติแพตเทิร์น

[แอนติแพตเทิร์น](https://en.wikipedia.org/wiki/Anti-pattern) คือโซลูชันสำหรับ "ปัญหาที่เกิดซ้ำ ซึ่งมักไร้ประสิทธิผลและเสี่ยงที่จะก่อผลตรงกันข้ามอย่างรุนแรง" การรู้วิธี*ไม่*แก้ปัญหาก็มีค่าพอๆ กับการรู้วิธีแก้ปัญหา แอนติแพตเทิร์นมอบตัวอย่างเปรียบเทียบที่ยอดเยี่ยมให้เราพิจารณาเทียบกับดีไซน์แพตเทิร์น แอนติแพตเทิร์นไม่ได้จำกัดอยู่แค่โค้ด ตัวอย่างเช่น กระบวนการทำงานก็เป็นแอนติแพตเทิร์นได้เช่นกัน
