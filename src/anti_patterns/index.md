# แอนติแพตเทิร์น

[แอนติแพตเทิร์น (anti-pattern)](https://en.wikipedia.org/wiki/Anti-pattern) คือรูปแบบวิธีแก้ปัญหาสำหรับ "ปัญหาที่เกิดขึ้นซ้ำๆ ซึ่งมักไม่ได้ผลและเสี่ยงที่จะก่อให้เกิดผลเสียมากกว่าผลดีอย่างยิ่ง" การรู้ว่าวิธีใดที่*ไม่ควรนำมาใช้*แก้ปัญหา มีคุณค่าไม่แพ้การรู้วิธีแก้ปัญหาที่ถูกต้องเลย แอนติแพตเทิร์นจึงเป็นตัวอย่างเปรียบเทียบในทางตรงกันข้ามชั้นเยี่ยม ให้เรานำมาพิจารณาควบคู่ไปกับดีไซน์แพตเทิร์น ทั้งนี้ แอนติแพตเทิร์นไม่ได้จำกัดอยู่เพียงแค่ในระดับโค้ดเท่านั้น ตัวอย่างเช่น กระบวนการทำงาน (process) ก็อาจเป็นแอนติแพตเทิร์นได้เช่นเดียวกัน
