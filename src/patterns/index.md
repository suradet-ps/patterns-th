# ดีไซน์แพตเทิร์น

[ดีไซน์แพตเทิร์น](https://en.wikipedia.org/wiki/Software_design_pattern) คือ "โซลูชันสำเร็จรูปที่นำกลับมาใช้ซ้ำได้ทั่วไป สำหรับปัญหาที่เกิดขึ้นบ่อยในบริบทหนึ่งๆ ของการออกแบบซอฟต์แวร์" ดีไซน์แพตเทิร์นเป็นวิธีที่ดีเยี่ยมในการอธิบายวัฒนธรรมของภาษาโปรแกรม ดีไซน์แพตเทิร์นมีความเฉพาะเจาะจงกับภาษาเป็นอย่างมาก สิ่งที่เป็นแพตเทิร์นในภาษาหนึ่งอาจไม่จำเป็นในอีกภาษาหนึ่งเพราะมีฟีเจอร์ของภาษา หรืออาจแสดงออกมาไม่ได้เลยเพราะขาดฟีเจอร์นั้น

หากใช้มากเกินไป ดีไซน์แพตเทิร์นอาจเพิ่มความซับซ้อนที่ไม่จำเป็นให้กับโปรแกรม อย่างไรก็ตาม มันเป็นวิธีที่ดีเยี่ยมในการแบ่งปันความรู้ระดับกลางถึงระดับสูงเกี่ยวกับภาษาโปรแกรม

## ดีไซน์แพตเทิร์นใน Rust

Rust มีฟีเจอร์เฉพาะตัวมากมาย ฟีเจอร์เหล่านี้ให้ประโยชน์มหาศาลแก่เราโดยกำจัดปัญหาไปทั้งกลุ่ม บางฟีเจอร์ยังเป็นแพตเทิร์นที่*มีเฉพาะ*ใน Rust อีกด้วย

## YAGNI

YAGNI เป็นตัวย่อของ `You Aren't Going to Need It` เป็นหลักการออกแบบซอฟต์แวร์ที่สำคัญยิ่งที่ควรนำมาใช้ขณะเขียนโค้ด

> โค้ดที่ดีที่สุดที่ผมเคยเขียน คือโค้ดที่ผมไม่เคยเขียน

หากเรานำ YAGNI มาปรับใช้กับดีไซน์แพตเทิร์น จะเห็นว่าฟีเจอร์ของ Rust ช่วยให้เราทิ้งแพตเทิร์นไปได้หลายแบบ ตัวอย่างเช่น ไม่จำเป็นต้องมี[กลยุทธ์ (strategy pattern)](https://en.wikipedia.org/wiki/Strategy_pattern) ใน Rust เพราะเราใช้ [traits](https://doc.rust-lang.org/book/traits.html) ได้เลย
