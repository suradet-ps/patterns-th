# โฟลด์

## คำอธิบาย

รันอัลกอริทึมบนสมาชิกแต่ละตัวในคอลเลกชันของข้อมูลเพื่อสร้างสมาชิกใหม่ กลายเป็นคอลเลกชันใหม่ทั้งชุด

ที่มาของคำนี้ผมหาไม่ได้ชัดเจนนัก คำว่า 'fold' และ 'folder' ถูกใช้ในคอมไพเลอร์ของ Rust แม้ว่าในสายตาของผมมันดูเหมือนการ map มากกว่าการ fold ในความหมายปกติ ดูรายละเอียดเพิ่มเติมได้ในหัวข้อการอภิปรายด้านล่าง

## ตัวอย่าง

```rust,ignore
// The data we will fold, a simple AST.
mod ast {
    pub enum Stmt {
        Expr(Box<Expr>),
        Let(Box<Name>, Box<Expr>),
    }

    pub struct Name {
        value: String,
    }

    pub enum Expr {
        IntLit(i64),
        Add(Box<Expr>, Box<Expr>),
        Sub(Box<Expr>, Box<Expr>),
    }
}

// The abstract folder
mod fold {
    use ast::*;

    pub trait Folder {
        // A leaf node just returns the node itself. In some cases, we can do this
        // to inner nodes too.
        fn fold_name(&mut self, n: Box<Name>) -> Box<Name> { n }
        // Create a new inner node by folding its children.
        fn fold_stmt(&mut self, s: Box<Stmt>) -> Box<Stmt> {
            match *s {
                Stmt::Expr(e) => Box::new(Stmt::Expr(self.fold_expr(e))),
                Stmt::Let(n, e) => Box::new(Stmt::Let(self.fold_name(n), self.fold_expr(e))),
            }
        }
        fn fold_expr(&mut self, e: Box<Expr>) -> Box<Expr> { ... }
    }
}

use fold::*;
use ast::*;

// An example concrete implementation - renames every name to 'foo'.
struct Renamer;
impl Folder for Renamer {
    fn fold_name(&mut self, n: Box<Name>) -> Box<Name> {
        Box::new(Name { value: "foo".to_owned() })
    }
    // Use the default methods for the other nodes.
}
```

ผลลัพธ์ของการรัน `Renamer` บน AST คือ AST ใหม่ที่เหมือนกับตัวเดิมทุกประการ แต่ทุกชื่อถูกเปลี่ยนเป็น `foo` ตัวโฟลด์ในชีวิตจริงอาจมีสถานะที่เก็บไว้ระหว่างโหนดใน struct ของมันเอง

ตัวโฟลด์ยังนิยามให้แมปโครงสร้างข้อมูลหนึ่งไปยังโครงสร้างข้อมูลอีกอัน (ซึ่งโดยปกติคล้ายกัน) ได้ด้วย ตัวอย่างเช่น เราอาจ fold AST ให้กลายเป็นต้นไม้ HIR (HIR ย่อมาจาก high-level intermediate representation)

## แรงจูงใจ

เป็นเรื่องปกติที่ต้องการแมปโครงสร้างข้อมูลโดยดำเนินการบางอย่างกับแต่ละโหนดในโครงสร้าง สำหรับการดำเนินการง่ายๆ บนโครงสร้างข้อมูลง่ายๆ เราทำได้ด้วย `Iterator::map` สำหรับการดำเนินการที่ซับซ้อนขึ้น เช่นกรณีที่โหนดก่อนหน้าอาจส่งผลต่อการดำเนินการกับโหนดถัดไป หรือกรณีที่การวนซ้ำบนโครงสร้างข้อมูลไม่ง่าย การใช้แพตเทิร์นโฟลด์จะเหมาะสมกว่า

เช่นเดียวกับแพตเทิร์นผู้มาเยือน แพตเทิร์นโฟลด์ช่วยให้เราแยกการท่องไปในโครงสร้างข้อมูลออกจากการดำเนินการที่ทำกับแต่ละโหนดได้

## การอภิปราย

การแมปโครงสร้างข้อมูลในลักษณะนี้พบได้ทั่วไปในภาษาเชิงฟังก์ชัน ในภาษา OO การแก้ไขโครงสร้างข้อมูลในที่เดิมจะพบได้บ่อยกว่า แนวทาง 'เชิงฟังก์ชัน' พบได้ทั่วไปใน Rust ส่วนใหญ่เป็นเพราะความนิยมในความไม่เปลี่ยนรูป (immutability) การใช้โครงสร้างข้อมูลใหม่แทนการแก้ไขของเดิมทำให้การทำความเข้าใจโค้ดง่ายขึ้นในเกือบทุกสถานการณ์

เราสามารถปรับสมดุลระหว่างประสิทธิภาพกับความสามารถในการใช้ซ้ำได้ โดยเปลี่ยนวิธีที่โหนดถูกส่งเข้าเมท็อด `fold_*`

ในตัวอย่างข้างต้นเราดำเนินการบนพอยน์เตอร์ `Box` เนื่องจากพอยน์เตอร์เหล่านี้เป็นเจ้าของข้อมูลแต่เพียงผู้เดียว สำเนาต้นฉบับของโครงสร้างข้อมูลจึงไม่สามารถนำกลับมาใช้ใหม่ได้ ในทางกลับกัน หากโหนดไม่ถูกแก้ไข การใช้มันซ้ำก็มีประสิทธิภาพสูงมาก

หากเราดำเนินการบนเรฟเฟอเรนซ์แบบยืม โครงสร้างข้อมูลต้นฉบับยังนำกลับมาใช้ใหม่ได้ แต่โหนดต้องถูกโคลนแม้ไม่เปลี่ยนแปลง ซึ่งอาจมีค่าใช้จ่ายสูง

การใช้พอยน์เตอร์แบบนับเรฟเฟอเรนซ์ให้ทั้งสองข้อดีรวมกัน - เราทั้งใช้โครงสร้างข้อมูลต้นฉบับซ้ำได้ และไม่ต้องโคลนโหนดที่ไม่เปลี่ยนแปลง อย่างไรก็ตาม มันใช้งานสะดวกน้อยกว่า และหมายความว่าโครงสร้างข้อมูลจะแก้ไขไม่ได้

## ดูเพิ่มเติม

อิเทอเรเตอร์มีเมท็อด `fold` แต่เมท็อดนั้นจะ fold โครงสร้างข้อมูลให้กลายเป็นค่า ไม่ใช่โครงสร้างข้อมูลใหม่ เมท็อด `map` ของอิเทอเรเตอร์ใกล้เคียงกับแพตเทิร์นโฟลด์นี้มากกว่า

ในภาษาอื่น คำว่า fold มักใช้ในความหมายของอิเทอเรเตอร์ใน Rust มากกว่าแพตเทิร์นนี้ ภาษาเชิงฟังก์ชันบางภาษามีโครงสร้างที่ทรงพลังสำหรับทำ map ที่ยืดหยุ่นบนโครงสร้างข้อมูล

แพตเทิร์น[ผู้มาเยือน](../behavioural/visitor.md)มีความสัมพันธ์ใกล้ชิดกับโฟลด์ ทั้งคู่มีแนวคิดร่วมกันคือการท่องไปในโครงสร้างข้อมูลโดยดำเนินการกับแต่ละโหนด อย่างไรก็ตาม ผู้มาเยือนไม่ได้สร้างโครงสร้างข้อมูลใหม่และไม่ได้บริโภคของเดิม
