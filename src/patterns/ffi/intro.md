# แพตเทิร์น FFI

การเขียนโค้ด FFI เป็นหลักสูตรทั้งคอร์สในตัวมันเอง อย่างไรก็ตาม มีสำนวนหลายอย่างในนี้ที่ใช้เป็นเครื่องชี้ทางและช่วยหลีกเลี่ยงกับดักสำหรับผู้ใช้ Rust แบบ `unsafe` ที่ยังไม่มีประสบการณ์

ส่วนนี้รวบรวมดีไซน์แพตเทิร์นที่อาจมีประโยชน์เมื่อทำ FFI

1. [API แบบอิงออบเจกต์](./export.md) ที่มีคุณสมบัติด้านความปลอดภัยของหน่วยความจำที่ดี และมีขอบเขตชัดเจนว่าส่วนใดปลอดภัยและส่วนใดไม่ปลอดภัย

2. [การรวมชนิดเข้าเป็นตัวห่อ](./wrappers.md) - จัดกลุ่มชนิดข้อมูล Rust หลายชนิดไว้ด้วยกันเป็น "ออบเจกต์" ทึบแสง
